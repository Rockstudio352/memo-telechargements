# Mémo : téléchargements

**Mémo** transforme vos réunions en comptes rendus professionnels : synthèse, décisions actées et plan d'actions.
Application : https://memo-1o3.pages.dev

Ce dépôt contient uniquement les fichiers à télécharger. Ils servent à **détecter automatiquement vos réunions** et à les enregistrer.

## Mémo pour Windows

Pour toutes les réunions qui utilisent le micro : Zoom, Teams, Google Meet, WhatsApp, Webex…

1. Téléchargez **[Memo-Setup.exe](https://github.com/Rockstudio352/memo-telechargements/releases/latest/download/Memo-Setup.exe)** (environ 116 Mo).
2. Ouvrez le fichier. Windows peut afficher « Windows a protégé votre ordinateur » : cliquez sur **Informations complémentaires**, puis **Exécuter quand même**. L'application n'est pas encore signée numériquement.
3. Connectez-vous à votre compte Mémo dans la fenêtre qui s'ouvre.
4. Mémo reste ensuite dans la zone de notification, en bas à droite de l'écran. Quand une réunion commence, une notification vous propose de l'enregistrer.

## Extension Chrome et Edge

Pour les réunions dans le navigateur : Google Meet, Teams web, Zoom web.

1. Téléchargez **[memo-extension.zip](https://github.com/Rockstudio352/memo-telechargements/releases/latest/download/memo-extension.zip)** et décompressez-le dans un dossier que vous gardez.
2. Ouvrez `chrome://extensions` (ou `edge://extensions`) et activez le **Mode développeur**.
3. Cliquez sur **Charger l'extension non empaquetée** et choisissez le dossier décompressé.
4. Sur la page d'accueil qui s'ouvre, cliquez sur **Autoriser le micro**, puis épinglez l'icône Mémo.

Pensez à prévenir les participants que la réunion est enregistrée.
